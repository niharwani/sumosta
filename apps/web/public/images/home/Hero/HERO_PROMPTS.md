# SUMOSTA — Hero Banner Prompts (v2, marketing edition)

Use these with **ChatGPT (GPT-4o Image / GPT-Image-1)**. For each slide, upload the referenced product PNG as an attached image, then paste the prompt.

- Output size: **1792 × 1024 (landscape)**
- Format: PNG, 300dpi feel
- Save the outputs into this folder as `Hero1.png`, `Hero2.png`, `Hero3.png` (overwrite the existing files).

Brand guardrails — **carry these into all 3 prompts** so the set feels like a series:
- Palette: cream `#FFFDF8`, warm ivory `#FFF9F0`, soft gold `#FFE0A8`, primary honey `#F5A623`, deep honey `#D4891A`, charcoal `#2C2417`, midnight `#1A150E`
- Typography: **Clash Display** (bold display sans) for the main headline, **Bespoke Serif italic** for eyebrow / accent word, **Satoshi** for supporting body copy, **all-caps letter-spaced sans** for the CTA tag
- Mood: liquid-gold minimalism, editorial luxury food photography meets premium apothecary — Aesop meets Maison Margiela, warmer. Cinematic side-light, faint dust motes, soft honey bokeh
- Composition: text-left / product-right, generous negative space, thin gold hairline accents, no clutter
- Absolutely NO stock-photo look, NO shiny cartoon honey drops, NO farm/cottage kitsch, NO emojis, NO bees crawling on jars
